# ornl-utome.github.io

Project page for [UtoMe](https://github.com/ornl-utome/UtoMe), served at https://ornl-utome.github.io.

## Local preview

```bash
python3 -m http.server 51784 --bind 127.0.0.1
```

Open <http://127.0.0.1:51784/>. No build step or external video service is needed.

The blue tokens on a near-white mint background, centered Without uncertainty / UtoME (Ours) demo and E/P/S method animation play silently and loop while visible. On narrow screens the method uses a portrait sequence. There are no video tabs or player overlays. The navigation's pause button controls all motion; reduced-motion preferences start with still posters.

The original paper PDF and figures are unchanged. Video sources and evaluation scope are recorded in [assets/video/README.md](assets/video/README.md).
